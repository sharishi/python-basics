# **Индивидуальная работа**

## **Описание задания**

Индивидуальная работа заключается в **доработке лабораторной работы №7**, разработанной с использованием Flask.

Основная цель — **расширить функциональность существующего веб-приложения**, улучшив его структуру, удобство использования и возможности работы с данными.


## **Обязательный минимум (базовые требования)**

Студент должен обязательно реализовать:

* улучшенную работу с базой данных (добавление, корректное получение и отображение данных);
* обработку ошибок (например: несуществующий ID, пустые формы и т.д.);
* улучшенную валидацию данных в формах;
* улучшение пользовательского интерфейса (минимальное оформление: стили, структура страниц).


## **Дополнительные требования**

Помимо обязательного минимума, необходимо реализовать **не менее 3 дополнительных функций по выбору студента**.

Примеры направлений (студент может предложить свои):

* расширение логики работы с данными;
* улучшение взаимодействия пользователя с приложением;
* добавление новых страниц или возможностей;
* элементы аналитики;
* другие функциональные улучшения.

## **Требования к отчету**

Отчет должен содержать:

* титульный лист;
* содержание;
* введение;
* краткое описание лабораторной работы №7;
* описание внесенных доработок;
* примеры кода;
* скриншоты работы приложения;
* вывод.


## **Критерии оценки**

Оценка зависит от:

* сложности реализованных доработок;
* качества реализации;
* структуры и читаемости кода;
* качества отчета;
* понимания студентом своей реализации.

## **Результат**

Студент должен представить:

* доработанное веб-приложение;
* отчет;
* демонстрацию работы приложения.
